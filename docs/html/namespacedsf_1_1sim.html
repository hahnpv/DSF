◆ IntegrandType

enum class dsf::sim::IntegrandType
strong

Tag for integrand type — used by symplectic integrators to distinguish position-like states (q) from momentum-like states (p).

Non-symplectic integrators ignore this tag.

Enumerator
GENERIC 

Default — integrated normally by all methods.

POSITION 

Position-like (q): dq/dt = v (function of momentum)

MOMENTUM 

Momentum-like (p): dp/dt = F (function of position)
