Detailed Description

template<class BClass>
class dsf::sim::TClassDict< BClass >

Singleton dictionary of class factories.

Stores TClassBase pointers for all registered classes deriving from a common base class. Enables runtime creation of objects by class name.

Template Parameters
BClassBase class that all registered classes derive from.

Usage

// Get existing singleton instance:
Block* b = TClassDict<Block>::Instance()->Get("MyModel", true);
dsf::sim::Block
Base class for all simulation model blocks.
