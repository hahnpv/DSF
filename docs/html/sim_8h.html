Detailed Description

Top-level simulation executive.

Sim owns the main simulation loop: it advances the clock, calls the integrator, fires reports, and checks termination conditions. A single Sim instance manages one block-tree + clock + output chain.

Usage

dsf::sim::Sim sim;
sim.load(root_block, 0.01, 600.0, 1.0, 0.1);
sim.run();
