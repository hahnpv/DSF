void dsf::sim::IntegratorVerlet::propagate ( Block *  root)
overridevirtual

Störmer-Verlet (velocity Verlet) symplectic integration.

For each step:

  1. Half-kick: p_{n+½} = p_n + (dt/2) * dp/dt(q_n)
  2. Drift: q_{n+1} = q_n + dt * dq/dt(p_{n+½})
  3. Evaluate derivatives at new position
  4. Half-kick: p_{n+1} = p_{n+½} + (dt/2) * dp/dt(q_{n+1})

Integrands tagged POSITION are q-like (updated in drift step). Integrands tagged MOMENTUM are p-like (updated in kick steps). Integrands tagged GENERIC are treated as MOMENTUM (force-driven).
