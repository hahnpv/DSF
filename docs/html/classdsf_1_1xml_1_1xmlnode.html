Detailed Description

Stateful XML node navigator.

Wraps Boost Property Tree to provide an intuitive API for XML navigation. Maintains a parent stack for multi-level parent() traversal.

Usage

xml doc("config.xml");
doc.parse();
xmlnode& root = *doc.xmlRoot;
for (auto child : root.children()) {
std::string id = child.attrAsString("id");
Vec3 pos = child.attrAsVec3("position");
}
