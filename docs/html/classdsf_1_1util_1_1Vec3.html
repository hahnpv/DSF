Detailed Description

3D vector class.

Represents a 3-component vector with x, y, z members. Supports standard vector operations and operator overloading.

Usage

Vec3 position(100, 200, 300);
Vec3 velocity(1, 2, 3);
Vec3 acceleration = force / mass;
double speed = velocity.mag();
