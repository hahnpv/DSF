Detailed Description

3x3 matrix class.

Stores matrix as three row vectors (a0, a1, a2). Supports common matrix operations for coordinate transformations.

Usage

Mat3 rotation(1,0,0, 0,cos(th),-sin(th), 0,sin(th),cos(th));
Vec3 body_velocity = rotation * inertial_velocity;
Mat3 inv = rotation.inv();
